# Список серверов для test-doh.sh и install-dnsproxy.sh. Одна строка = один сервер.
# Файл подхватывается автоматически, если лежит рядом со скриптом.
#
# Формат: АДРЕС [ОПЕРАТОР]
#   https://… tls://… quic://…  кандидат в Upstream DNS Server (DoH/DoT/DoQ)
#   голый IPv4                  кандидат в Bootstrap и Fallback DNS Server
#
# ОПЕРАТОР — кто держит сервер. В итоговые списки сначала берётся лучший
# адрес каждого оператора и только потом вторые адреса тех же операторов:
# пять адресов Cloudflare — это не пять независимых upstream. Без метки
# оператором считается домен второго уровня, а для IP — сам адрес.
# Разные имена одного оператора оставлены намеренно: блокируют часто по
# имени (SNI), и одно имя может работать, когда другое закрыто.
#
# Родительских (family) фильтров здесь нет: в режиме parallel побеждает самый
# быстрый ответ, и фильтр 18+ в общем пуле блокировал бы сайты случайным
# образом. Фильтры вредоносного и рекламы (Quad9, AdGuard и т. п.) срабатывают
# так же случайно, но это безобидно.
# Строки с # игнорируются.
